Problem:
Guess a random number generated by computer.

1. IPO Model:
--------------------------------------------------
Input   : guess (numeric guess entered repeatedly by user)
Process : 1. Computer generates target number (1 - 100).
          2. Loop until guess == target:
               Read user's guess.
               If guess < target, show "Too low! Try again."
               Else if guess > target, show "Too high! Try again."
               Else, show "Congratulations! Correct!"
Output  : Feedback messages ("Too low", "Too high", "Congratulations!")

2. Pseudocode:
--------------------------------------------------
START
    GENERATE target = random integer between 1 and 100
    SET attempts = 0
    SET guess = 0
    
    WHILE guess != target DO
        PROMPT "Enter your guess: "
        INPUT guess
        SET attempts = attempts + 1
        
        IF guess < target THEN
            PRINT "Too low! Try again."
        ELSE IF guess > target THEN
            PRINT "Too high! Try again."
        ELSE
            PRINT "Congratulations! You guessed correctly in " + attempts + " attempts!"
        ENDIF
    ENDWHILE
END
