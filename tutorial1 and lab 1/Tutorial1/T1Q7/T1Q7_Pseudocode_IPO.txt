Problem:
Print the number of odd and even number from 10 random numbers generated by computer. The random number must be from 10 - 100.

1. IPO Model:
--------------------------------------------------
Input   : None (computer generates 10 random numbers in range 10 - 100)
Process : Initialize evenCount = 0, oddCount = 0
          Repeat 10 times:
            Generate random number num (10 - 100)
            If num % 2 == 0:
                evenCount = evenCount + 1
            Else:
                oddCount = oddCount + 1
Output  : evenCount, oddCount

2. Pseudocode:
--------------------------------------------------
START
    SET evenCount = 0
    SET oddCount = 0
    
    FOR i = 1 TO 10 DO
        GENERATE num = random integer between 10 and 100
        PRINT num
        
        IF num MOD 2 == 0 THEN
            SET evenCount = evenCount + 1
        ELSE
            SET oddCount = oddCount + 1
        ENDIF
    ENDFOR
    
    PRINT "Number of even numbers: " + evenCount
    PRINT "Number of odd numbers: " + oddCount
END
