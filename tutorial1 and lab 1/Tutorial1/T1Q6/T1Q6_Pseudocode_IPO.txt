Problem:
Print the minimum number from 10 random numbers generated by computer.

1. IPO Model:
--------------------------------------------------
Input   : None (computer generates 10 random numbers)
Process : Generate 10 random numbers.
          Store the first number as minimum (min).
          Loop through remaining 9 numbers:
            If current number < min, update min = current number.
Output  : The generated numbers and the minimum number.

2. Pseudocode:
--------------------------------------------------
START
    GENERATE first random number, SET min = first number
    PRINT first number
    
    FOR count = 2 TO 10 DO
        GENERATE num (random number)
        PRINT num
        IF num < min THEN
            SET min = num
        ENDIF
    ENDFOR
    
    PRINT "Minimum number: " + min
END
